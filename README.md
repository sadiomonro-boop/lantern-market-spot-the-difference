Lantern Market is a spot-the-difference game set in a night market: three hand-drawn-in-code scenes (Lantern Lane, Noodle Stall, Lantern Workshop), 7 fair differences each, with a timer, limited hints, keyboard and mouse play, and procedural sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
